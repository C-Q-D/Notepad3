## 布局

- 主窗口客户区底色 `#0C0D0C`。侧栏和编辑器各是一块圆角「岛」，互相间隔 8，四周留 8（顶部 2）。
- 侧栏岛：默认宽 300，圆角 16，底色 `#121412`，1px 描边 `rgba(255,255,255,.06)`，阴影 `0 14px 36px rgba(0,0,0,.5)`。
- 编辑器岛：圆角 12，1px 描边 `rgba(255,255,255,.05)`；内部配色仍由编辑器主题决定。
- 侧栏内部从上到下：标题区 → 筛选框 → 可滚动区（「最近打开」+「文件夹」，筛选时换成匹配结果）→ 底部状态条。

## 侧栏各部分

| 部分 | 设计 |
|---|---|
| 字体 | 侧栏全部等宽：`Cascadia Mono`，退到 `Consolas`；中文退到 `Microsoft YaHei UI`。正文 12.5，次要 11.5。 |
| 标题区 | 第一行 `❯ Notepad3`：`❯` 用强调色，名称 14.5 加粗。第二行是上级路径 `D:\可直接运行程序\`，灰色，过长时尾部省略。右侧两个直径 30 的圆形按钮：新建文件、刷新。 |
| 筛选框 | 高 34，全圆角胶囊，底色 `#1A1E1A`；左侧强调色 `/` 提示符；聚焦时描边 `#3F5C41`；有内容时右侧出现清除按钮。 |
| 分组标题 | `# 最近打开`、`# 文件夹`，灰色 12，后面跟 `−` / `+` 表示展开或收起。`[清除]`、`[折叠]` 只在鼠标悬停到标题时出现。「文件夹」标题右侧显示根目录计数，如 `4 目录 · 5 文件`。 |
| 最近打开 | 最多 4 项，每行：`▸`（只有当前文件有）、序号、文件名、右对齐的所在文件夹（`Themes\`、根目录写 `.\`、根目录外的写缩略路径）。当前文件的文件名用强调色加粗。没有记录时显示「打开过的文件会出现在这里」。 |
| 文件夹树 | 不显示根节点。每行用线框字符做前缀：同级最后一项用 `└─`，否则用 `├─`；上层还没画完的补 `│  `，已画完的补三个空格。文件夹名后加 `/`，蓝色加粗；收起时在后面用灰色显示子项数，如 `Docs/  (10)`，空文件夹显示 `(空)`。展开的空文件夹下面显示一行灰色 `└─ （空）`。 |
| 行高 | 24（设计稿里比较过 22 和 28）。行圆角 7，左右内边距 10。 |
| 当前打开的文件 | 整行实心强调色胶囊，文字 `#0B0C0B` 加粗，线框前缀用半透明深色，行尾小字「编辑中」。 |
| 选中（光标） | 底色 `#1F261F`。选中和当前打开是两回事：键盘移动或点文件夹只改变选中。 |
| 悬停 | 底色 `#181C18`。 |
| 底部状态条 | 高 30，底色 `#0F110F`。左侧强调色块写「文件栏」，中间是当前文件相对根目录的路径（有提示时换成提示文字，琥珀色 `#E6C07B`），右侧 `.*`（显示隐藏文件）、`a→z`（排序）两个文字按钮。 |

## 交互（设计稿中能点的部分）

- 点文件夹：展开或收起，并选中这一行。
- 点文本文件：在编辑器打开，成为当前文件；它所在的各级文件夹自动展开；它移到「最近打开」第一位。
- 点二进制文件（`.exe` `.dll` `.mui`）：只选中，不在编辑器打开，底部状态条提示「二进制文件，不在编辑器中打开」。
- 筛选：按文件名不区分大小写地包含匹配，范围是整个根目录（包括收起的文件夹）；结果每行显示文件名（命中部分用强调色淡底高亮）和所在文件夹；无结果时显示提示和 `[清除筛选]`。
- `[清除]` 清空最近打开；`[折叠]` 收起全部文件夹；工具栏第一个按钮显示或隐藏整个侧栏。

## 只是示意、实现前要确认的部分

- 新建文件、刷新、`.*`、`a→z` 这几个按钮在设计稿里只有外观，没有定义行为。
- 「二进制文件不在编辑器中打开」「筛选范围包括收起的文件夹」是设计里的提议，现有实现没有这些行为。
- 「最近打开」打算用 Notepad3 已有的最近文件记录；具体取哪份数据、最多几项，实现时再定。
- 编辑器区只预置了 5 个文件的开头几行，用来演示点击后切换，跟侧栏实现无关。
- 定稿没有覆盖：根文件夹未设置、根文件夹不存在、浅色主题、高 DPI 缩放、侧栏拖窄后的表现。
