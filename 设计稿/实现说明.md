- **照做**：按设计稿实现。
- **替代做法**：目标做到了，但做法或外观和设计稿不同。原因写在同一行。

## 设计点对照

### 布局

| 设计点 | 状态 | 说明 |
|---|---|---|
| 主窗口客户区底色 `#0C0D0C` | 照做（仅深色） | 浅色模式用系统窗口色 |
| 两岛间隔 8，四周 8，顶部 2 | 照做 | 两岛之间的 8 像素空隙就是拖动改宽度的位置，替代原来的分隔条 |
| 侧栏默认宽 300 | 照做 | 只改默认值，已保存的宽度不变 |
| 侧栏圆角 16、底色 `#121412`、1px 描边 | 照做 | 用 GDI+ 抗锯齿绘制；描边按 DPI 缩放，最少 1 像素 |
| 侧栏阴影 | 没做 | Win32 子窗口画柔和阴影要分层窗口或离屏合成，代价大，收益小；方案阶段已确认不做 |
| 编辑器岛圆角 12 | 替代做法：方角 | 编辑器是 Scintilla 子窗口，做圆角要裁剪窗口区域，会影响滚动条和重绘；方案阶段已确认用方角 |
| 编辑器 1px 描边 | 照做（仅深色） | 描边色是 `rgba(255,255,255,.05)` 混到 `#0C0D0C` 上的不透明色；浅色模式不加描边和外边距 |
| 侧栏内部顺序：标题区 → 筛选框 → 滚动区 → 状态条 | 照做 | |

### 设计稿没覆盖的情况

| 情况 | 做法 |
|---|---|
| 根文件夹未设置 | 标题显示「未打开文件夹」；「文件夹」组下显示 `[打开文件夹…]`；新建、筛选禁用（新建按钮不画底色圆，只留线框色的淡加号）；最近打开照常，刷新后选中保留 |
| 根文件夹不存在 | 保留 INI 里的路径；显示「文件夹不存在」和 `[重试]` `[重新选择…]`；状态条琥珀色提示完整路径；新建、筛选禁用，外观同上；启动时也进入这个状态，不空白 |
| 拖窄 | 逻辑宽度小于 220 隐藏「编辑中」、最近打开的所在文件夹列、计数；小于 160 再隐藏圆形按钮、「文件栏」色块、`.*`、`a→z`；被隐藏的元素也点不到；放不下的文字尾部省略 |
| DPI 变化 | 字体、行高、圆角、内边距、描边按新 DPI 重建 |

## 原有行为

以下原有行为已由界面测试覆盖：

- 切换根文件夹。
- 打开文件时同步选中并展开各级文件夹。
- 刷新后恢复展开状态。
- 树里的 Enter、F5 不被主窗口快捷键抢走。
- 主题变化及同 DPI 下重建样式后保留选中。真实跨 DPI 切换未实测，范围见下节。

### 验证边界

- **真实高 DPI：UNVERIFIED。** 两台显示器的 Windows 有效 DPI 均为 96；已测缩放计算和同 DPI 重建，未改系统缩放，也未用合成 `WM_DPICHANGED` 冒充跨 DPI 实测。
- **真实鼠标悬停和提示框：UNVERIFIED。** 禁用按钮点击无效、工具提示命中区域为空、静态外观均有证据。隐藏桌面的合成鼠标移动未使正常按钮的悬停颜色改变，阳性对照不成立，不能据此声称真实悬停背景和停留提示框已通过。
- **默认 DirectWrite 的编辑区视觉：UNVERIFIED。** 默认模式启动及编辑器实际文本读写通过，但隐藏桌面的 `PrintWindow` 未完整捕获编辑区。交付的完整画面采用临时 GDI 设置，不能作为默认 DirectWrite 编辑区绘制的直接证据。
- 一次临时测试脚本在功能断言前失败。该实例核对身份后正常关闭、进程已退出，但退出码未能读取；未计入上述六次有效启动。修正测试脚本后的主要功能检查已通过。
